# Gamer Cleaner

Steamライブラリの不要ファイルを見つけて、安全にゴミ箱へ移動するElectronアプリ(MVP)。

## 現状のスコープ

- **対象**: Windows + Steam(ライブラリのルートフォルダ = `steamapps` を含むフォルダ)を想定
- **分類ロジック**は拡張子だけで判断せず、`steamapps/common/<game>` のような
  フォルダ構造を手がかりに、以下の4段階に分ける:
  - 🟢 **safe** — シェーダーキャッシュ、`_CommonRedist`、Steamのダウンロード中/一時ファイルなど。
    既定でチェック済み、まとめてゴミ箱へ移動できる
  - 🟡 **uninstall** — ゲーム本体のフォルダ。手動削除ではなくSteamのアンインストーラーを使うよう案内するのみ(削除しない)
  - 🔴 **critical** — セーブデータらしき名前のフォルダ、OS/システム領域など。常に保護し、削除UIの対象にしない
  - ❔ **unknown** — 自動判定できなかったもの。一覧には出すが、削除は手動判断に委ねる
- **削除は必ずゴミ箱経由**(`shell.trashItem`)。完全削除は行わない。誤って消しても復元できる

## セットアップ(あなたのPCで)

```
cd cleaner
npm install
npm start
```

このセッションはGUIを表示できないサーバー上で動いているため、実際の画面確認はできていません。
スキャン・分類ロジック(`src/classifier.js` / `src/scanner.js`)は `node --test` でユニットテスト済みです。

```
npm test
```
